# Connect-Four
Implementation of the game 'Connect Four' as a side project from 2018.

![](https://user-images.githubusercontent.com/83593808/151780186-7e4eddfd-36f2-47d7-9fff-840c13a96011.png)

You play against a bot that has been implemented with the [minmax algorithm](https://en.wikipedia.org/wiki/Minimax). 
For executing the application you have to run __BoardGUI__ from the root folder.
